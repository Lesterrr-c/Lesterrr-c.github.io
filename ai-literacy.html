02 / PERSONAL REFLECTION

What I learned from AI.

01

What did AI help me accomplish?

AI helped me plan my portfolio, improve page layouts, develop CSS animations, troubleshoot coding issues, and organize technical case-study documentation.

02

What did I personally verify?

I reviewed the suggested code, applied changes in VS Code, and tested the website through my local development environment. I checked the loading animation and navigation behavior.

03

What did I learn?

I learned that AI can help explain concepts and solve programming problems, but I still need to understand the code, test the results, and make my own technical decisions.

04

What limitations did I discover?

AI-generated solutions may depend on existing file paths, CSS styles, and JavaScript behavior. For example, the loading animation needed shared CSS so it could display across different pages.
