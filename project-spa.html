PROJECT DOCUMENTATION

JNIEL's Body Massage & Spa

Web-Based Appointment and Management System

Project Overview

JNIEL's Body Massage & Spa is a web-based system designed to manage customer appointments and assist with basic spa business operations.

Problem

The project was developed to provide a more organized way of handling customer information, services, appointments, and other spa management tasks.

Objective

The main objective was to develop a functional web application that allows customers to make appointments while providing administrators with tools to manage the system.

My Role

I worked on the development of the system, including the user interface, database integration, authentication, appointment functionality, and administrative features.

Technologies

PHP MySQL HTML CSS JavaScript Bootstrap XAMPP Git GitHub

Development Process

1. Planning

I identified the main requirements of the system, including customer registration, appointment booking, service management, and administrative functions.

2. Design

I planned the structure of the customer and admin interfaces and organized the system into separate pages and functions.

3. Development

I implemented the system using PHP, MySQL, HTML, CSS, and JavaScript. I also connected the application to the database and implemented its main functions.

4. Testing

I tested the system by checking registration, authentication, appointments, database operations, email verification, and other system functions.

5. Debugging

When errors occurred, I examined the error messages, checked the related code, identified the cause, and tested the changes until the problem was resolved.

6. Improvement

I continued improving the system based on testing results and identified problems during development.

Key Features

  • Customer registration and login
  • Email verification using OTP
  • Appointment booking
  • Service management
  • Therapist management
  • Customer management
  • Admin dashboard
  • Appointment management
  • Email notifications and reminders
  • Reports

Challenges

During development, I encountered problems involving PHP file paths, database connections, authentication, OTP verification, and email configuration.

Solutions

I solved these problems through debugging, testing, checking error messages, reviewing the system structure, and making incremental changes to the application.

What I Learned

This project improved my understanding of PHP development, database integration, authentication, CRUD operations, debugging, Git/GitHub, and building a complete web application.
