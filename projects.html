WEB APPLICATION

JNIEL's Body Massage & Spa

Project Overview

A web-based appointment management system developed for JNIEL's Body Massage & Spa. The system helps manage customer appointments, services, therapists, and other basic business operations.

Technologies

PHP MySQL HTML CSS JavaScript Bootstrap XAMPP Git GitHub

Purpose

To provide a centralized system for handling spa appointments and basic business management functions.

My Role

I worked on the development of the system, including the interface, database integration, authentication, appointment features, and administrative functions.

Key Features

  • Customer registration and login
  • Email verification using OTP
  • Appointment booking
  • Service management
  • Therapist management
  • Customer management
  • Admin dashboard
  • Appointment management
  • Email notifications
  • Reports

Challenges

I encountered problems involving PHP file paths, database connections, authentication, OTP verification, and email configuration. These required debugging and testing during development.
