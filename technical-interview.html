02 / MOCK INTERVIEW

Questions to practise.

Answer aloud first, then reveal the guidance. Focus on understanding instead of memorizing.

01 What is the difference between an array and a variable?
Explain that a variable stores a value, while an array holds multiple indexed values. Give a simple example in a programming language you know.
02 What is the difference between a primary key and a foreign key?
A primary key uniquely identifies a row in a table. A foreign key references a key in another table, helping establish a relationship between records.
03 What is the difference between HTML, CSS, and JavaScript?
HTML defines page structure, CSS controls presentation and layout, and JavaScript adds behavior and interactivity.
04 What roles do DNS and DHCP perform?
DNS translates domain names into the records needed to locate services. DHCP automatically assigns network configuration, such as IP addresses, to clients.
05 How can a web developer help prevent SQL injection?
Use parameterized queries or prepared statements for data values, validate inputs appropriately, restrict database permissions, and avoid exposing sensitive database errors to users.
06 What would you do if your code worked before but now fails?
Reproduce the problem, examine error messages, identify recent changes, isolate the failing component, test a hypothesis, apply a fix, and retest the affected functionality.

These are starting points, not memorized scripts. Practise giving your own explanation and supporting it with a real example.
